# webЯcade Application: Nintendo DS Emulator

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

The Nintendo DS application for [webЯcade](https://www.webrcade.com)  is an emulator for the [Nintendo DS](https://en.wikipedia.org/wiki/Nintendo_DS) handheld game console.

The underlying emulator is a modified version of the Libretro fork of [melonDS](https://github.com/libretro/melonds).

## Documentation

The [Nintendo DS Application Documentation](https://docs.webrcade.com/apps/emulators/nds/) includes [keyboard](https://docs.webrcade.com/apps/emulators/nds/#keyboard), [gamepad](https://docs.webrcade.com/apps/emulators/nds/#gamepad), and [touch](https://docs.webrcade.com/apps/emulators/nds/#touch) control mappings, information related to [battery-backed SRAM](https://docs.webrcade.com/apps/emulators/nds/#battery-backed-sram) support, as well as information related to utilizing the emulator within a [webЯcade feed](https://docs.webrcade.com/apps/emulators/nds/#feed).
